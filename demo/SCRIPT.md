# PQ PayGuard demo video

Narrated 1080p walkthrough for the DoraHacks QDay Aevum Builder Challenge
submission. Everything below is produced locally and repeatably; no API keys,
no signed-in browser, no account of any kind.

## Files

| File | Role |
| --- | --- |
| `demo/narration.txt` | Voiceover source. One sentence per line, blank line between paragraphs. |
| `demo/steps.json` | The drive plan. `at` steps pin actions to narration marks (`"mark": "2.1"` = paragraph 2 sentence 1, resolved through `timing.json`). |
| `demo/timing.json` | Measured per-sentence start/duration from the synthesized audio. Regenerated by `synth`. |
| `demo/narration.wav` | Assembled voiceover (macOS `say`, voice Samantha, 180 wpm, 24 kHz mono). |
| `demo/captions.ass` | Lower-third captions burned into the video (white on a translucent dark box). |
| `demo/pq-payguard-demo.srt` | Companion captions file for upload forms. |
| `demo/pq-payguard-demo.mp4` | The finished video. |
| `scripts/record-demo.mjs` | The whole pipeline: `synth`, `capture`, `check`, `all`. |
| `scripts/serve.mjs` | Zero-dependency static server used by `capture`. |

## Reproduce

```bash
npm run demo:synth     # narration.txt -> narration.wav + timing.json + captions
npm run demo:capture   # serve + headless Chrome drive -> demo/pq-payguard-demo.mp4
npm run demo:check     # ffprobe + volumedetect report
```

`capture` starts `scripts/serve.mjs` on an ephemeral port, drives the app in
a throwaway headless Chrome (empty profile, remote debugging port 0, real
mouse and key events, a visible drawn cursor, downloads denied), resamples
the screencast to a constant 30 fps, muxes the narration and burns the
captions in one ffmpeg pass (`h264` `yuv420p` `+faststart`, `aac`). All temp
files live in `PQPAYGUARD_DEMO_TMP` (or a fresh `mkdtemp` dir) and are
deleted on exit. It aborts if the page ever navigates off the demo origin.

## Honesty note

The video is an honest capture of this repo running in a plain browser. The
escrow walkthrough runs `PayGuardSim`, the same branch-exact mirror the anvil
suite checks against real EVM bytecode; no testnet or mainnet transaction is
claimed anywhere in the narration or on screen. The one network call shown is
the page's own opt-in `Probe testnet` button, which did read the live Aevum
RPC during this recording (chain id `44005`); the narration also states the
marked-simulation fallback. Signature material is the in-page keccak based
Lamport, WOTS and merkle construction, the hash family SLH-DSA descends
from; the risk model scores `ml-dsa-*` and `slh-dsa-*` scheme labels as
listed in `src/risk.js`. The `387` test figure is the real `npm test` +
`forge test` count (`287` JavaScript + `100` Foundry); `scripts/browser-check.mjs`
audits the live page over `72` checks, and `test/pipeline.test.js` proves the
cap gate's first failing check equals the real `PayGuardSim` revert across a
1,440-scenario grid.
